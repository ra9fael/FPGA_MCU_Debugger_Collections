## 来源与使用范围

硬件文件来自本仓库历史提交；V9 Mini 和隔离版的已知来源见各目录。资料沿用原作者署名和已有许可；本次整理不授予新的许可证。部分历史资料未附明确许可，使用或再分发前应向相应权利人核实。

本项目与 SEGGER 无隶属或背书关系。需要完整调试器时，请选择官方或授权产品；软件获取和使用范围以 [SEGGER 官方资料](https://www.segger.com/products/debug-probes/j-link/)及随附许可为准。
