# V9 Mini Historical Hardware Notes

[中文](./readme.md) | **English**

The historical source is the shuanghanbitian/JLinkMini project. Its mixed archive included software, firmware and operating instructions and is no longer distributed here.

The original hardware description lists an STM32F205-series MCU, Type-C, SWD and UART interfaces, and a 20.7 mm × 12.95 mm four-layer PCB. These details record a historical design, not a complete build procedure or software authorization.

This directory retains hardware reference material. It does not provide J-Link software, firmware, or feature-licensing procedures.
