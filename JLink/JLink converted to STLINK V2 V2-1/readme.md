# ST-LINK on-board 官方资料

**中文** | [English](./readme_en.md)

SEGGER 提供面向指定 ST-LINK on-board 设备的官方转换方案。支持的评估板、目标器件、用途及其他许可限制，以 [SEGGER 官方页面](https://www.segger.com/products/debug-probes/j-link/models/other-j-links/st-link-on-board/)和工具随附许可为准。

本目录仅提供官方资料入口，不提供工具或固件副本，也不提供面向任意 ST-LINK 或自制硬件的转刷步骤。官方支持某些设备不等于授权其他硬件使用同一软件。

[MB1180.pdf](./MB1180.pdf) 为历史收录的 ST 参考原理图，权利归原权利人；它不构成 J-Link 软件使用许可。
